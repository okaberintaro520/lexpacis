# 安全边界与运行权限

这是本项目的具体实现边界，不是零风险保证、完整渗透测试或法律合规认证。

## 本次没有采用的路径

- 未安装反向代理、内网穿透、远程控制程序、VPN、中转站客户端或常驻远程入口。
- 未把本机服务暴露到公网。预览程序只监听 127.0.0.1。
- 未执行来源网站的 JavaScript、下载未知程序、关闭 TLS 校验、绕过验证码或付费墙。
- 未读取浏览器密码、WorkBuddy 登录文件、个人邮件或系统账户凭证。
- 没有在网页中嵌入模型密钥、发布令牌或个人数据库。

## 依赖来源

引注引擎从 Juris-M/citeproc-js 的官方维护仓库获得，样式从 citation-style-language 与 Zotero 中文社区仓库获得。固定提交、原始网址、SHA-256 和许可记录于 config/citation-assets.json。完整源码与许可随交付包和网站分发。运行时不从第三方 CDN 加载 JavaScript、字体或样式。

保留第三方许可并不代表作者为本平台背书。这里做了依赖来源、校验值与常见注入路径检查，没有对约百万字节的引擎实施逐行安全审计。

## 来源文本与模型输出

来源 HTML 只作为文本解析；RSS 的原文链接不会变成终端命令。模型只能输出约定的结构化字段，不能添加脚本、发布地址、系统命令或凭证读取要求。

apply 只读取 runtime/workbuddy 内的输出；CFP apply 只读取 runtime/cfp 内的输出。两者检查来源版本和字段。CFP 自动更新使用已经实际读取且身份匹配的公告页面，不把未读取的新链接当作已核实公告。

引注表单与结构化导入只接受受限字段。展示时转义或白名单清理 HTML；不执行导入对象。没有远程样式上传、eval 或自定义代码功能。

## 网络访问

只请求配置中登记的 HTTP(S) 公开地址，标准端口，不携带个人站点 Cookie。采集程序不自动使用环境变量里的代理；也不会安装或配置代理。系统已有网络路由仍由用户操作系统管理。

网络策略拒绝本地、私有、链路本地、保留地址和未获准重定向，禁止 HTTPS 降级。发现 VPN 的虚拟 DNS 映射到保留地址时也会拒绝，不自动放松。需要由用户在可信正常网络下使用；不能把关闭安全检查当作恢复方案。

地址预检和允许列表降低误访问风险，但并不是对 DNS 重绑定和全部网络威胁的完备防护。这里处理的是固定、低频、公开学术信源，不接受公众提交任意抓取 URL。

浏览器引用格式化完全本地。只有用户主动点击“读取 DOI”才请求 api.crossref.org；此请求不带凭证并禁止传 Referer。不要将保密未发表材料主动输入第三方查询服务。

## WorkBuddy 权限

把工作空间限定到本项目文件夹。允许固定更新命令与必要发布操作，不授予整盘、系统配置、密码存储或任意对外发送权限。用户登录发布平台应走其官方授权网页，不把口令粘贴给模型。

项目说明不能强制改变 WorkBuddy 的沙箱、默认审批或宿主权限。这些仍需在客户端中按实际版本设置；未宣称已替你配置。

## 发布和隐私

只上传 dist/ 或 lexatlas-web.zip。完整交接包包含 runtime 的私有证据、数据库与任务文件，不能当作公开网站上传。收藏和脚注清单保存在浏览器，不进入站点构建。

静态网页不提供访客远程执行接口。无需为本站开放路由器端口。正式域名、托管和备案应通过正规服务商完成，不使用免费域名转售、中介代备案或未知中转绕过访问限制。

## 本地检查

```powershell
python scripts/security_audit.py
```

检查覆盖固定依赖哈希、公开文件中的私有目录、外部执行资源和基本浏览器策略；不会发起扫描别人服务器的行为。
