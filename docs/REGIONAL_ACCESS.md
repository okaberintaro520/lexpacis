# 无需 VPN、零新增费用与地区可达性

核查日期：2026-11-18。用户明确优先零额外费用，目前没有自己的域名或服务器，也要求不使用未知中转、反向连接或内网穿透。

## 可以直接保证的交付范围

网站是可迁移的静态文件。HTML、CSS、JS、引注引擎、CSL 样式和已收录数据都在发布包中，不依赖 Google Fonts、外部 CDN、第三方前端服务或模型接口。

解压 lexatlas-web.zip 后，双击 index.html 即可在本机使用搜索、筛选、收藏、CFP 导航和引注格式化。这个离线入口不需要 VPN，也不需要将电脑开放到公网。读取 DOI 与访问原文仍需要相应来源可达；已经保存的数据和本地格式化不受影响。

这解决本机访问和文件分发，不等于已经建立可持续更新的国内公网托管。

## 当前在线地址

本次 Sites 地址可查看更新后的成果，但用户已报告在其网络中需要 VPN。不能继续把它称为面向中国大陆的稳定正式入口。改站名也不会改变这一网络条件。

## 免费托管不能被误当成全球可达承诺

- [Cloudflare China Network 官方 FAQ](https://developers.cloudflare.com/china-network/faq/) 对 Pages 在中国内地的可用性有限制。普通免费 Pages 套餐不等于已接入其中国网络服务。
- [Vercel 官方说明](https://vercel.com/kb/guide/accessing-vercel-hosted-sites-from-mainland-china) 明确无法保证中国大陆的可用性和表现。换个默认免费子域名不能被当作已解决。
- [EdgeOne 国内站域名管理](https://edgeone.cloud.tencent.com/pages/document/162936836982489088) 写明：默认项目域名按加速区域可能要求 3 小时有效预览链接，或者在中国大陆返回 401。
- [EdgeOne Makers 域名概览](https://pages.edgeone.ai/zh/document/domain-overview) 同样对中国大陆默认域名访问列出 3 小时预览限制，并建议自定义域名。不能用短期链接冒充长期直连地址。

## 对本项目的决定

不购买服务、不绕过平台限制、不申请不明免费域名、不把个人电脑作为反向隧道源站。不因现成免费入口限制而降低安全设置。

在零新增费用且无域名/托管资源的前提下，目前交付“可离线使用 + 可向正规平台直接部署”的结果，但不能负责地承诺一个长期、所有地区均可直接访问的公网地址。此项仍未完成网络实测，不得在宣传或运营日志中写成已实现。

网站已采用相对资源路径，迁移时不需要改前端代码；修改 site.json 的 base_url 并重新 build，更新正式地址相关信息。零费用约束未放宽前，不默认启用其他服务。

## 合规与安全

国内托管涉及的域名、备案和其他要求，以所在地、服务类型和正规服务商现行规则为准。[阿里云 OSS 静态网站说明](https://help.aliyun.com/zh/oss/user-guide/hosting-static-websites)区分了自定义域名与内地备案要求。本文件没有把学术资讯站认定为已经满足所有监管要求，也不提供代备案渠道。

只上传公开静态包，不上传完整交接包。不要公开本机目录，不配置路由器端口映射，不提供远程控制权限。具体实现边界见 SECURITY.md。
