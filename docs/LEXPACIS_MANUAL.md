# Lexpacis 读者使用指南

[打开网站](https://lexpacis.github.io/)。浏览资讯、使用引注转换和保存收藏都无需注册。

## 浏览与检索

- 按「研究文献」「学术活动」「官方资料」「案件进展」「学术评论」浏览，或从研究专题进入相关资料。
- 可以搜索标题、作者、DOI 和关键词，再按信源、时间和排序缩小范围。「收录时间」是资料进入平台的时间；「发布日期」以来源提供的日期为准。
- 点标题打开详情，查看原标题、出处、资料类型和原文链接。点「独立页面」可分享单条资料。正式引用前请对照原文核对材料和日期。

## 收藏与书目导出

1. 点条目右侧的收藏图标，在「我的研究清单」查看收藏。
2. 用「备份收藏 JSON」保存文件，换浏览器或设备时选择「恢复收藏」。恢复会合并备份和已有收藏。
3. 用「导出 Zotero 书目」生成 CSL JSON。打开 Zotero，选择 **File → Import… → A file**，选中导出的文件。导入后请核对机构作者、案号和文书类型。[Zotero 导入说明](https://www.zotero.org/support/kb/importing_standardized_formats)

## 引注转换

1. 在资讯详情点「生成引注」，或直接进入引注工作台。书目可以手填，也可用 DOI 查询或导入 RIS、CSL JSON。
2. 核对题名、作者、期刊或机构和出版日期。在引文定位栏填写实际引用的页码或段落。
3. 选择样式并预览。可复制到 Word 脚注，也可加入清单、调整顺序或起始编号后批量导出。

当前可选《法学引注手册》第二版社区 CSL、OSCOLA 第 4 版 CSL、Bluebook Law Review CSL 和 Chicago 第 18 版脚注与书目。复杂判例、条约和期刊专用规则请用目标规范复核。[牛津 OSCOLA 说明](https://www.law.ox.ac.uk/oscola)

## 征稿、活动与订阅

- 「CFP 征稿」分为期刊征稿、会议征文、期刊投稿导航、待确认线索。可以按刊名、题目、语言、方向或截止情况筛选。投稿开放状态和期限请以原始公告为准。
- 「学术活动」可以切换为日历。日历页和 CFP 页各提供 ICS 链接，可添加到自己的日历应用。
- 需要持续追踪时，将首页的总 RSS，或栏目、专题的 RSS 链接添加至订阅阅读器。
