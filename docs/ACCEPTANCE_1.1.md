# 1.1 升级验收记录

日期：2026-11-18。

## 已实现并实际验证

引注工作台提供 4 个固定、可溯源的 CSL 样式。中文期刊脚注、英文期刊、具体页码与连续引用输出已在 Edge 浏览器中检查；OSCOLA 的 ibid、Bluebook 的 Id.、Chicago 的短引注分别由真实引擎产生，不是写死的演示字符串。中文样式使用第二版社区实现；OSCOLA 明确标作第 4 版，并提醒第 5 版已发布。

支持平台条目带入、手动编辑、RIS / CSL JSON、主动 DOI 查询、脚注清单、顺序调整、复制和导出。DOI 路径用模拟 Crossref 响应测试；未将该模拟结果写入公开数据。复制路径采用浏览器测试替身，不改变系统剪贴板。

CFP 页面包含 36 种期刊入口：14 种中文或中英文、22 种英文。当前发布数据包含 4 条本次核对原始页面的公告，其中 2 条期刊公告、2 条会议征文；另外有 3 条从既有订阅发现的待确认线索。三者身份分开，目录条目不冒充正在征稿。

常规期刊入口与征稿页面有受限检查程序；最多继续读取一层、6 个已批准主机上的明确 CFP 链接。模型更新需保留实际页面、证据版本、原句和明确日期。CFP、RSS、日历和 JSON 的隐藏控制共用配置。

集中改名测试通过，修改配置后首页、数据、日历等同步变更，网址不变。未替用户决定新名称。

## 测试

- 40 项 Python 测试通过，涵盖原有流程及新增 CFP 校验、来源归属、撤下、输出目录限制、改名、保留地址拒绝、未知主机拒绝、HTTPS 降级拒绝。
- 新功能浏览器检查通过：四种样式、再引、手动字段、导入导出、模拟复制、模拟 DOI、条目带入、CFP 分类、语言/关键词筛选、桌面与手机布局。
- 原有 22 组浏览器回归检查通过，无页面脚本错误或静态资源 HTTP 失败。
- 浏览器完全离线后仍能通过 file:// 运行引用格式化，实际得到包含具体页码的脚注。离线包不需要 VPN；主动 DOI 查询和访问来源原文除外。
- 11 个固定第三方文件的 SHA-256 校验通过；打包样式与原始 CSL/语言文件一致。
- 安全检查未发现公开目录中的私有数据库、外部执行资源或缺失的基础浏览器策略。检查范围不等于完整渗透测试、供应商认证或法律合规认证。

## 安全行为与限制

没有安装代理、内网穿透、反向连接、远程控制或新常驻服务。预览仅监听本机。没有读取用户账户密码、浏览器凭证或 WorkBuddy 登录文件。第三方依赖来自官方维护仓库，固定提交且保留源码/许可。

本次环境将期刊域名解析到保留地址，新安全策略拒绝连接，所以不能说 36 个入口都已由本机成功验证。状态如实公开；不会通过关闭校验或未知中转恢复。原有 187 条资料保留。
